# 🛍️ Why this User Experience?

### The Cold-Start Problem

A marketplace new marketplace starts by attracting a small number of shoppers. Consequently, sellers don’t want to invest time and resources to setup stores at a marketplace. Shoppers in turn don’t want to browse a marketplace with a small selection. This is known as the cold-start problem.&#x20;

### The Switching-Pain Problem

Shoppers have very low tolerance for changing habits. So the idea of getting used to a new marketplace, a new user interface, new ways of reading the information, low review count, new rules & policies is already painful. In addition, marketplaces have to fight for buyers’ attention. Not only is it a high “marketing” cost for shoppers' attention, it requires constant reinforcement. Shoppers wonder if the "discounts" are really worth it and end up defaulting back to their well established habits.

### <mark style="color:blue;">**So to answer "Why is the user experience built the way it is?"**</mark>

Dema addresses these two problems by enabling shoppers to browse anywhere & through the magic of order management integrations, sellers don’t need to setup a Dema storefront.
