# 📨 Introduction

## The TWO roles of a Marketplace

### **Provide product & Seller information discovery tools**

Shoppers use mobile & desktop apps to browse for items they’re interested in. These discovery tools present price, but also focus on presenting reviews, ratings and other elements that relate to reputation so the shoppers can make an informed decision.&#x20;

### **Arbitrate Trust**

If a dispute arises, the marketplace resolves this using clear rules & policies known to both parties: The two-sides (hence a two-sided marketplace). In essence, the marketplace’s fee is the price of “trust”.&#x20;
