# 🍯 User Value Proposition

The [**demo videos**](demo.md) show how Shoppers and Sellers experience the below first hand.&#x20;

{% tabs %}
{% tab title="Shoppers" %}
* **Get instant discounts on any item starting Day ONE**: Why shop with no incentive? Dema provides a discount on any price. From the seller fees, Dema provides a minimum 5% discount to the shopper. This works on any price, even deeply discounted prices.
* **Generate instant Trust**: Price, reviews & policies is how shoppers make decisions. So the UX ensures shoppers can visit the sites they like, view the same reviews, buy the exact SKU from the same seller with the same policies. Dema's UX is built for near-instant trust.
* **Shop anywhere**: If shoppers are used to shopping on Amazon.com, Etsy, etc..., why ask them to change habits? Instead, Dema enables them to continue.
* **Free instant ownership**: Dema points are earned for free with every purchase and when a referral makes a purchase. We call it [**shop-2-earn**](#user-content-fn-1)[^1]. Shoppers need only buy & refer others.
{% endtab %}

{% tab title="Sellers" %}
* **2-3x more profits via 3x lower selling (on day One) & $0 ad fees**: On day one, sellers pay a single 7.5% vs 25%+ total fees (incl. ads) on Amazon (for e.g.). At scale, this becomes 10x lower at 2.5% (automatically contract). Checkout the [**Unit Economics**](unit-economics.md) for the breakdown.
* **No Dema store for the Seller to setup/manage**: Sellers don't want to invest in yet another store setup if there are no customers. So Dema uses existing seller listings pulled from their existing inventory systems when shoppers browse. **Instant virtual listings.** **Zero effort**.
* **No new backend & no changes to how/where sellers fulfill**: Dema's >25 API-enabled e-commerce platform integrations cover >95% of e-commerce tx volume & takes <10min to setup & test. Sellers make **no changes** to how they receive orders or ship them out.
* **Free instant ownership**: Like shoppers, sellers earn Dema points upon shopper payment.
{% endtab %}
{% endtabs %}
